# 🎮 Rock-Paper-Scissors Game in C++

A console-based **Rock-Paper-Scissors game** developed in **C++** as a practical programming project.

This project brings together several fundamental programming concepts in one interactive application, including random number generation, user input validation, enums, structs, functions, loops, conditional logic, score tracking, and a simple computer opponent.

---

## 📌 Project Overview

The player competes against the computer in multiple rounds of Rock-Paper-Scissors.

The program:

- Reads and validates the player's choice.
- Generates a random choice for the computer.
- Determines the winner of each round.
- Tracks player wins, computer wins, and draws.
- Displays the results in a structured format.
- Allows the player to replay the game.

The main goal of this project was not only to build a game, but also to **practice problem-solving and combine multiple C++ concepts into one complete program**.

---

## 🧠 Programming Concepts Covered

This project integrates **20 programming concepts and techniques**:

1. **Generating Random Numbers**  
   Generate random values within a specific range.

2. **Handling User Input**  
   Read and validate Rock-Paper-Scissors choices.

3. **Working with Enums**  
   Represent game choices and winners using `enum`.

4. **Conditional Logic**  
   Use `if` and `switch-case` for decision making.

5. **Using Structures (Structs)**  
   Store related game information using structures such as:
   `stRoundInfo` and `stGameResults`.

6. **String Manipulation**  
   Convert enum values into readable text using functions such as:
   `ChoiceName()` and `WinnerName()`.

7. **Loops**  
   Use `for` and `while` loops to handle multiple rounds.

8. **Creating Functions**  
   Divide the program into reusable functions such as:
   `ReadPlayer1Choice()` and `PlayGame()`.

9. **Generating Computer Choices**  
   Simulate a simple computer opponent using random choices.

10. **Comparing Values**  
    Compare player and computer choices to determine the winner.

11. **Game Loop & Replay Feature**  
    Allow the user to play multiple games.

12. **Clearing the Console Screen**  
    Use system calls to refresh the screen between games.

13. **Tracking Scores**  
    Keep track of player wins, computer wins, and draws.

14. **Boolean Logic**  
    Determine whether the game should continue.

15. **Returning Values from Functions**  
    Use `return` values from functions such as:
    `WhoWonTheRound()` and `WhoWonTheGame()`.

16. **Switch-Case Decision Making**  
    Organize game logic using `switch-case`.

17. **Using `srand(time(NULL))`**  
    Initialize the random number generator to produce different results.

18. **Handling Edge Cases**  
    Validate input and prevent invalid choices.

19. **Simple AI / Computer Player**  
    Generate decisions for the computer opponent.

20. **Debugging & Output Formatting**  
    Display game results clearly and maintain structured output.
