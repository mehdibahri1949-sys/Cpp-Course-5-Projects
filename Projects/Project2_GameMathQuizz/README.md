# 🧮 Math Quiz Game in C++

A console-based **Math Quiz Game** developed in C++ to practice programming fundamentals, strengthen problem-solving skills, and apply multiple concepts in one interactive project.

The game generates math questions, allows players to choose difficulty levels and operation types, checks their answers, and calculates their final results.

## 🎮 Project Overview

The Math Quiz Game challenges players to solve arithmetic questions and tests their mathematical accuracy.

Depending on the implemented features, the game can include:

- Different difficulty levels: Easy, Medium, and Hard.
- Multiple arithmetic operations: Addition, Subtraction, Multiplication, and Division.
- Randomly generated questions.
- Answer validation and instant feedback.
- Score tracking and correct/incorrect answer counts.
- Final results and performance evaluation.

The project combines game logic, user interaction, and problem-solving techniques in a single C++ console application.

- **Variables and Data Types** — Store questions, answers, scores, and game settings.

- **Structures (`struct`)** — Group related information into organized data structures.

- **Parameters and Return Values** — Pass information between functions and return calculated results.

### Problem-Solving Techniques

- **Input Validation** — Handle player choices and prevent invalid selections.
- **Question Generation** — Create arithmetic questions according to selected settings.
- **Answer Checking** — Compare the player's answer with the correct result.
- **Score Tracking** — Count correct and incorrect answers.
- **Difficulty Management** — Adjust question complexity based on the selected level.
- **Operation Selection** — Apply different arithmetic operations.
- **Game Flow Control** — Manage the sequence of questions and quiz rounds.
- **Result Evaluation** — Calculate and display the final performance.
- **Code Reusability** — Use functions to avoid unnecessary repetition.


**Windows:**
