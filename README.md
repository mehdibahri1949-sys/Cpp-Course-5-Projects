# C++ Course 5 Projects

A collection of beginner-friendly C++ projects developed to strengthen programming fundamentals, algorithmic thinking, and problem-solving skills.

## 📂 Projects

1. Rock-Paper-Scissors ✊📄✂️

An interactive game that applies conditional statements, loops, functions, input validation, and game logic.

2. Math Quiz Game 🧮

An interactive quiz game featuring mathematical questions, difficulty levels, user input, scoring, and result evaluation.

## 🎯 Learning Goals

Practice fundamental C++ concepts.

Improve algorithmic thinking and problem-solving.

Apply functions, loops, conditionals, and data structures.

Build practical projects from programming exercises.

Learning by doing — one project at a time. 🚀
